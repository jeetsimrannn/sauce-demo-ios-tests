# SauceDemo iOS Automation Tests
Automated tests for the SauceDemo iOS app using WebdriverIO and Appium.

## Tests
- Login
- Add to cart and checkout with login
- Add to cart and checkout without login
- Sort funtionality test for products

## Run Tests
Start Appium:
  bash
  appium

Run tests:
  bash
  npx wdio run wdio.conf.js

## Tech Stack
- WebdriverIO
- Appium
- XCUITest
- Mocha
- JavaScript
